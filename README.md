# 📊 Receipt Scanner Bot

Telegram-бот для автоматического учёта покупок по QR-кодам из чеков. Распознаёт чек через API ФНС, сохраняет данные в базу и предоставляет аналитику по ценам на продукты.

## 🚀 Возможности

- **Загрузка чека по QR-коду** — отправьте боту данные из QR-кода, и он сам распарсит чек и сохранит все позиции
- **Общая статистика** — топ продуктов по сумме покупок с группировкой по названию
- **Детальная аналитика по продукту** — минимальная, максимальная и средняя цена, ценовой разброс, тренд изменения цены, история цен
- **Удаление продукта** — возможность убрать товар из статистики
- **Машина состояний** — бот понимает контекст диалога и ожидает нужный ввод от пользователя

## 🛠 Стек технологий

- Java 17
- Spring Boot
- Telegram Bots API
- OkHttp
- JPA / Hibernate
- PostgreSQL
- JSON (org.json)

## 📋 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/receipt_upload` | Загрузить чек по QR-коду |
| `/stats` | Общая статистика по всем продуктам |
| `/product_stats` | Детальная статистика по конкретному продукту |
| `/delete_product` | Удалить продукт из статистики |
| `/help` | Справка |

## 🔄 Как это работает

1. Пользователь отправляет боту QR-код из чека
2. Бот через `OkHttp` отправляет запрос к API ФНС и получает JSON с детализацией
3. Парсер извлекает название товара, количество, цену за единицу и итоговую сумму
4. Данные сохраняются в две таблицы: детализация покупок (`purchase_details`) и статистика цен (`product_stats`)
5. При запросе аналитики бот аггрегирует данные и формирует читаемый отчёт с эмодзи

## 🗄 Схема базы данных

### `purchase_details`
Хранит сырые данные из чеков: название продукта, количество, итоговая цена, дата покупки, признак весового товара.

### `product_stats`
Хранит агрегированную статистику: название продукта, цена за единицу и дата — для отслеживания динамики цен.
